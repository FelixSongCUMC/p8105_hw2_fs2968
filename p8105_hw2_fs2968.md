In the above code, we read in the NYC transit subway data-set that
includes information about the following points: line, station name,
station latitude and longitude, the route it lies on, whether there is
an entry and whether there is a fee, and the entrance type. To clean the
data, we first use the `clean_names` function from the janitor package
to ensure all of the column names are cleaned so that there are no dots,
uppercase, and overall more consistent. The next step was selecting all
of the columns that we want to keep using the `select` function applied
on the imported data. Note, since we wanted all route information, we
use the `starts_with` function to include all columns with names that
start with route to simplify the code. Lastly, we use the `mutate`
function to change the data-set, modifying the entry column to be a
logical vector with `TRUE` and `FALSE` instead of characters `"YES"` and
`"NO"`. In the import, you could consider declaring
`NA= c("NA", "", ".")` a cleaning step, but it is more of an
identification for the read_csv function of what the missing values will
be.

The post-clean data set has dim (1868, 19), which represents 1868
transit stations (rows) with 19 descriptor fields per row (columns).
After all of the cleaning, the data is mostly tidy. The names look good
and data typing is in line with normal standards, but one thing we are
missing is that some of the column names are observation values,
specifically route1,…,route11. Instead of separating these into 11
different groups, we should instead have this as one column for routes.

To find the number of distinct stations, which vary by name and line, we
can use the `distinct` and `nrow` functions:

``` r
nrow(distinct(t_data, station_name, line))
```

To reformat the data, we will use the `pivot_longer` function to change
the route columns to describe the route number as one column and the
route name as another. Before we do that, we first need to change the
route names to all be char because route 1,2,3,4,… are default to
doubles:

``` r
reformatted_t_data = 
  t_data |> 
  mutate(
    across(starts_with("route"), as.character)
  ) |> 
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name"
  )
```

Now we can answer the find the number of distinct stations that serve
the A train by using the `filter` function to only look at stations that
serve the A, and then use the `distinct` and `nrow` functions to find
the total distinct stations:

``` r
filter(reformatted_t_data, route_name == "A") |> 
  distinct(station_name, line) |> 
  nrow()
```

## Problem 2, Trash Wheel Dataset

We first read in the Trash Wheel Data-set and remove non-data entries
and not including dumpster specific data. We also can adjust the names
to be more reasonable and round the number of sports balls to the
nearest integer and conver to an interger type using `as.integer`.

``` r
trash_data = 
  readxl::read_excel(
    "data/202509 Trash Wheel Collection Data.xlsx", 
    sheet="Mr. Trash Wheel", 
    range="A2:N709",
    na = c("#", "")) |> 
  janitor::clean_names() |> 
  mutate(
    across(sports_balls, round),
    across(sports_balls, as.integer),
    owner = "Mr. Trash",
    across(year, as.double)
  )
```

excel sheets. This combined data-set includes 1188 observations (rows)

month, year, date, which help us identify the dumpsters and when the
were observed. The descriptive variables include weight_tons,
volume_cubic_yards, plastic_bottles, polystyrene, cigarette_butts,
glass_bottles, plastic_bags, wrappers, sports_balls, homes_powered,
owner, which describe the weight, volume, and breakdown of what is found
in the dumpster. The weight is measured in tons with mean value of
3.0619276, and the volume is measured in cubic yards with an mean value
of 15.047138. The other descriptive variables that detail what actual
items are in the dumpters use integer interpretations, for example, the
first 3 dumpsters had 584, 496, 1080 plastic bags.
